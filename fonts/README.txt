Put your two font files in this folder, named exactly like this
(any one format per font is enough; .woff2 is the smallest and best for the web):

  NeueMachina-Regular.woff2   (or .otf / .ttf)     <- headline + paragraph text
  AutheniaTextured.woff2      (or .otf / .ttf)     <- the word "Translate"

Until they are added, the page falls back to a system font, so it still works.
